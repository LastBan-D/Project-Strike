# Project Strike

Educational tactical FPS built with Unity and C#.

## Project Goals

- 2–4 multiplayer players
- Two opposing teams
- One playable map
- One rifle
- Bomb planting and defusing
- Round-based gameplay
- Online sessions with join codes
